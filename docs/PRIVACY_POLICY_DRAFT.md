# Privacy Policy Draft For Solarium

Last updated: 2026-07-18

Solarium is a sun exposure tracking app. This draft is for product planning and must be reviewed before App Store submission.

## Data Stored On Device

Solarium stores the following information locally on your device:

- Sun exposure sessions.
- Session start and end times.
- Session duration.
- Perceived sun intensity.
- Selected exposed body zones.
- Optional profile settings such as skin type, daily goal, and city.

## Data Export And Deletion

The app includes controls to export local data and delete local data from the device.

## Location

The current MVP does not request GPS location. A future Pro version may request location to estimate UV index. If location is added, the app should request permission only when the user enables UV features.

## Health Disclaimer

Solarium is for personal tracking and general wellness information only. It is not medical advice and does not diagnose, treat, cure, or prevent any condition.

## Third Parties

The current MVP does not send personal tracking data to third-party servers. If analytics, purchases, UV APIs, cloud sync, or account systems are added, this policy must be updated.
